## Description
This script is for task presentation for two experiments. 'exp1' correponds to the task in xxx paper. The scripts are adapted from the experiment scripts from David Meijer [1].

## Prerequisite
- Psychtoolbox-3
- MATLAB

## Usage
1. Before the expriment, generate trial sequence for each pariticipant (create_design.m).
2. Run compose_experiment.m and choose from the dropdown boxes the session type (training, practice or main experiment)

## Reference
1. Meijer, D., Veselic, S., Calafiore, C., & Noppeney, U. (2019). Integration of audiovisual spatial signals is not consistent with maximum likelihood estimation. Cortex, 119, 74–88. https://doi.org/10.1016/j.cortex.2019.03.026.
